[DayZModsWIP](https://github.com/c-Morette/DayZModsWIP)
This repository contains mods for DayZ inspired by the old game WarZ / Infestation: Survivor Stories (2012).
The goal is to recreate and adapt mechanics, objects, and systems that defined that game to the DayZ environment.

[Exodus_BaseBuild](https://github.com/c-Morette/Exodus_BaseBuild)
Base Building Mod, featuring the first underground bunker system in DayZ.
- [Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=2809506488)


[Askal_DynamicBook](https://github.com/c-Morette/Askal_DynamicBook)
A book item that opens in-game, with formatted pages (RichText), navigation buttons, and shortcuts to external links (YouTube, GitHub, Discord, and Steam). The content is loaded from a JSON in the server/player profile and can be updated without restarting the server.
- [Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3566484693)


[Askal_InsuranceMod](https://github.com/c-Morette/Askal_InsuranceMod)
Attention: OLD MOD, never Update this
This mod adds a complete item insurance system to DayZ, allowing players to protect their valuable equipment from loss due to death or other events. The system includes an administrative interface, detailed logs, and different categories of insurable items.
- [Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3553577226)


[Askal_SafeContainer](https://github.com/c-Morette/Askal_SafeContainer)
The SafeContainer System is a standalone mod for DayZ that provides secure containers attachable to the player, with full item persistence after death and an advanced restriction system.
-[Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3557308201)


[KeepItDead](https://github.com/c-Morette/KeepItDead)
The first DayZ mod published on Steam that, upon the player's death, transformed their character into a zombie that wandered around with their loot.
- [Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3536833285) | [OldMod](https://steamcommunity.com/sharedfiles/filedetails/?id=2608895186)


[FurnitureKits](https://github.com/c-Morette/FurnitureKits)
Very old storage mod
- [Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=2519713465)


[MyMaintenanceMod](https://github.com/c-Morette/MyMaintenanceMod)
This mod for DayZ adds a Base Maintenance (Protection) system, Jammer and KDU (Dog Tag) raids, and an event tracker.
- [Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3553008383)
